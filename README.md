# Teste — Web Share API com arquivo .vcf

Página descartável, criada para um único experimento: descobrir se o Chrome
no Android aceita compartilhar um cartão de contato (`.vcf`, `text/vcard`)
através de `navigator.share({ files })`.

Contém apenas dados fictícios (`Teste Valero`, `+55 41 99999-0000`,
`teste@example.com`). Não tem relação com nenhum sistema em produção e pode
ser apagada assim que o teste terminar.
